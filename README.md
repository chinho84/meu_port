# Portfólio — Inssa A. Abudo

Website pessoal para apresentar formação, experiência profissional, competências técnicas, projetos e artigos de investigação.

## Tecnologias
- HTML
- CSS
- JavaScript
- Git / GitHub

## Estrutura
- index.html — conteúdo do site
- style.css — estilos
- perfil.js — menu, tema e animações
- fotolink.jpg — foto de perfil
- cv-inssa-abudo.pdf — currículo
- Responsabilidade_social.pdf — artigo 1
- tecnologia-gestao-projetos.pdf — artigo 2

## Como atualizar
1. Editar os ficheiros no VS Code
2. Testar no navegador
3. Enviar para o GitHub:

git add .
git commit -m "mensagem clara da alteracao"
git push
